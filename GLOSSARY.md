# Promptify

Promptify is the company's internal prompt library, where employees create, edit, and share reusable prompts.

## Language

### Prompts

**Prompt**:
A single reusable piece of text with a title and descriptive metadata, written by one Author and visible to every User.
_Avoid_: Template, snippet, instruction, shared prompt

**Category**:
A classification from a closed list maintained by Administrators; every Prompt belongs to one or more Categories. Each Category has a name and a Color.
_Avoid_: Folder, type, tag
### People

**User**:
A company employee who can access Promptify.
_Avoid_: Member, account, employee

**Author**:
The User who created a given Prompt, and the only User who may edit it.
_Avoid_: Owner, creator, editor

**Administrator**:
A User who maintains the list of Categories.
_Avoid_: Admin, moderator, superuser
